# educa — дизайн-док v1.0

> Социальная платформа для школьников и студентов: сообщество + инструменты + честная модель монетизации.

## 1. Зачем

Каждый год миллионы абитуриентов мучаются с разрозненными сайтами приёмных комиссий. educa решает это **открыто и бесплатно**: открытые данные о вузах, сообщество и инструменты в одном месте.

**Анти-ЦИАН принцип:** не продавать справку о том, куда поступить, а отдать её людям. Деньги берём с тех, кому нужна аудитория — вузов и школ.

## 2. Модель монетизации (B2B)

- **Подписка вузов/школ: 500 ₽/мес** — «импульсная покупка B2B»: директор платит из кармана, без тендеров
- Что получает вуз: **сторис над лентой** (первые экраны абитуриентов) + посты в «Ленте вузов» с галочкой
- Математика: 100 подписчиков = 50 000 ₽/мес (хостинг покрыт); 500 = 250 000 ₽/мес
- Сезонность: продавать в **мае–июле**, когда комиссиям абитуриенты нужнее воздуха
- Growth-ход: первые 50 вузов — год бесплатно за обратную связь

## 3. Точка входа и удержание

- **Вход:** мини-квиз «60 секунд до карты твоего будущего» (предметы/баллы/город → персональный список вузов с шансами)
- **Удержание:** Задача дня со стриками, дневники абитуриентов, тиммейты
- **Этика:** хронологическая лента без дофаминовой петли — «мы возвращаем время, а не отбираем»

## 4. Структура главного экрана (проверено на прототипе)

1. **Шапка:** логотип (шрифт Pershotravneva55) + поиск + ⋮ (Настройки / Избранное / Тема)
2. **Истории:**
   - До прокрутки: большой ряд под шапкой («Моя история» с «+», вузы с голубыми кольцами)
   - При прокрутке: ряд уезжает наверх и **сворачивается в стопку из 3 кружков** рядом с логотипом ровно в момент полного исчезновения ряда за шапкой
   - Тап по историям/логотипу при прокрутке → плавный скролл наверх
   - Просмотрщик: автолистание слайдов → автопереход к следующей истории; тапы влево/вправо; **зажатие = пауза, драг влево/вправо = перемотка**; реакции (❤ + 🔥😂😍 с пузырьками); просмотренные сереют
3. **Pull-to-refresh:** тянешь ленту вниз → «Тяни вниз…» → «Отпусти — обновим» → спиннер → «Обновлено ✓»
4. **Овал-сегменты (вся ширина):** серый контейнер → белая целиковая «Подписки» + белая из двух половинок «Полезное | Офтопик» (перегородка). Голубым подсвечивается только выбранное
5. **Лента (Threads-стиль):** строки с тонкими разделителями; аватар-монограммы; галочка-печать верификации; тихий ⋮ справа (В избранное / Скопировать ссылку / Пожаловаться); вложения в едином стиле (шансы, таблица, мемы); реакции/действия со счётчиками
6. **Подписка:** кнопка «+» под аватаром только у неподписанных; тап → ✓ → исчезла (как в Threads)
7. **Док (плавающая пилюля):** Лента / Вузы / **Инструменты** (идентичность в центре) / Профиль
8. **Конец ленты:** кастомная SVG-иллюстрация (лупа с мордочкой) + «Это конец ленты… пока что»

## 5. Ключевые механики

- **Верификация:** синий значок-печать = проверенный оригинал (вузы, бот, люди). Без галочки — самозванец
- **Подписки:** на вузов и на людей; кнопка исчезает после подписки — лента чистая
- **Разделение контента:** вкладки = «откуда» (подписки/рекомендации), внутри рекомендаций режимы «Полезное / Офтопик»
- **Лента вузов** — отдельная вертикаль (B2B-витрина): объявления показываются только подписанным на вуз
- **Задача дня:** ежедневная задача + стрик (Duolingo-механика)
- **Тема:** светлая/тёмная, переключение — круговая волна от точки нажатия (View Transitions), прогрев и noanim против лагов
- **Без «резины»:** скролл внутри контейнера, overscroll отключён

## 9. Юридические заметки (форум с несовершеннолетними)

- Модерация обязательна; возрастная маркировка; ПДн детей до 14 — согласие родителей
- Сервис с общением пользователей = «организатор распространения информации» → реестр РКН, хранение данных в РФ
- Поэтому форум — фаза 2, сначала сообщество в Telegram (инфраструктуру держит TG)
