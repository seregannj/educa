# educa 🎓

> Открытая платформа для школьников и студентов: сообщество, инструменты и честные данные о поступлении.
> Анти-ЦИАН: бесплатно для людей навсегда. Вузы и школы платят 500 ₽/мес за то, чтобы их видели.

## Что внутри

- `index.html` — интерактивный прототип главного экрана (открывается без сборки)
- `fonts/pershotravneva55.css` — фирменный шрифт бренда (Pershotravneva55, Max Shirko) в виде data-URI
- `data/vuzy_rf_2026.csv` — открытые данные: 80 программ вузов Москвы, приём-2026
- `data/zarubezh_2026.csv` — 11 маршрутов бесплатного обучения за рубежом для россиян
- `docs/DESIGN.md` — дизайн-док: все решения, механики, палитра, дорожная карта

## Быстрый старт

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/index.html
```

Сборка не нужна — чистый HTML/CSS/JS.

## Принципы

1. **Бесплатно и открыто** — данные по лицензии CC BY-SA, код по MIT
2. **Источник у каждой цифры** — доверие через провенанс, как в Википедии
3. **Пользователи ничего не платят** — монетизация только B2B (вузы/школы)
4. **Не отбираем время** — хронологическая лента, никакой дофаминовой петли
