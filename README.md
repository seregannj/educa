# educa

Карта твоего будущего: вузы Москвы, проходные баллы приёма-2026, бюджетные места, стоимость обучения,
калькулятор шансов и бесплатные маршруты учёбы за рубежом.

Приложение выросло из интерфейсного прототипа: дизайн, истории, лента и механики сохранены, но теперь это
настоящее веб-приложение с маршрутами, каталогом и PWA.

## Стек

- **Next.js 15 (App Router) + TypeScript** — статические страницы каталога, клиентские экраны там, где нужны
  интерактивность и локальное состояние.
- **Чистый CSS** (дизайн-токены в `src/app/globals.css`), без UI-библиотек: визуал перенесён из прототипа 1:1.
- **Данные** — CSV в `data/`, скрипт `scripts/build-data.mjs` собирает из них типизированный JSON.
- **PWA** — manifest, service worker, офлайн-страница, установка на iOS/Android/десктоп.
- **Аккаунты и публикации** — Postgres (в разработке PGlite), сессии в HttpOnly-cookie, пароли на scrypt.
- **Локальное состояние** (стрик, избранное, просмотренные истории) — `localStorage`; посты, лайки и подписки — в базе.

## Быстрый старт

```bash
npm ci          # установить зависимости
npm run dev     # собрать данные и запустить http://localhost:3000
npm run build   # production-сборка
npm start       # запуск собранного приложения
```

`npm run dev` и `npm run build` сами пересобирают JSON из CSV. Отдельно: `npm run data`.

## Данные

- `data/vuzy_rf_2026.csv` — 13 вузов, 92 записи: ЕГЭ, проходные баллы, места, стоимость, примечания.
- `data/zarubezh_2026.csv` — 11 зарубежных маршрутов: стипендии, требования, дедлайны, источники.

Чтобы обновить цифры: поправьте CSV и выполните `npm run data`. Скрипт проверяет шапку таблицы и падает,
если структура поехала. JSON в `src/data/` генерируется, руками его не правят.

В каталоге и калькуляторе сравниваются только программы, где балл сопоставим с суммой ЕГЭ: без ДВИ и
400-балльных шкал (`comparable` в данных). Это осознанное ограничение, а не забытая логика.

## Деплой на Vercel

1. Импортируйте репозиторий в Vercel.
2. Framework Preset — **Next.js**, Build Command — `npm run build`, Install — `npm ci`.
3. Переменные окружения пока не нужны.
4. Для облачного dev-предпросмотра задайте `ALLOWED_DEV_ORIGINS` (список хостов через запятую) — только
   для локальной разработки, на production не влияет.

Домен подключается в настройках проекта. PWA работает на HTTPS-домене Vercel сразу.

## Аккаунты и база

- Регистрация и вход: `/register`, `/login`. Пароль — scrypt с солью, сессия — случайный токен в
  HttpOnly-cookie (в базе лежит только его SHA-256), срок 30 дней.
- Без `DATABASE_URL` приложение поднимает **PGlite** (Postgres в WASM) и хранит данные в `.data/pglite`.
  Это удобно локально, но на Vercel файловая система не сохраняется — там нужен внешний Postgres.
- В продакшене задай `DATABASE_URL` (например, строка подключения Neon/Supabase). Схема создаётся сама
  при первом запросе.
- Публикация: посты в ленте (до 600 символов, рубрики «Полезное / Офтопик / Мемы»), истории из 1–3 слайдов,
  лайки, подписки на авторов, удаление своих постов.

```bash
cp .env.example .env.local   # раскомментируй и вставь DATABASE_URL для продакшена
```

## Что уже работает

- Лента: истории с автолистанием и реакциями, вкладки, лайки, подписки, избранное, меню поста, задача дня.
- Аккаунты, свои и чужие профили (`/u/handle`), публикация постов и историй, подписки, удаление своих постов.
- Каталог: поиск по вузу/программе/предмету, фильтры по сферам, «только с бюджетом», сортировка по баллам.
- Карточка вуза: статистика, программы, ссылка на сайт приёмной комиссии.
- Калькулятор шансов: сумма трёх ЕГЭ + ИД, оценка по проходным 2026.
- Зарубежные маршруты с покрытием стипендии и дедлайнами.
- Свой профиль, избранное, настройки, тёмная тема с сохранением.
- PWA: установка, офлайн-оболочка, инструкции под iOS/Android/десктоп.
- Предложение правки данных: черновик, markdown-заявка, копирование в один клик.

## Лицензии и юридические заметки

- Код — открытый; данные собраны по официальным сайтам приёмных комиссий (ссылки в CSV).
- Шрифт **Pershotravneva55** (Max Shirko) встроен как data-URI. Перед коммерческим запуском нужно
  подтвердить условия использования шрифта у правообладателя.
- Для аккаунтов несовершеннолетних потребуется политика обработки персональных данных и согласие
  родителей — учесть до запуска регистрации (см. `docs/DESIGN.md`).
